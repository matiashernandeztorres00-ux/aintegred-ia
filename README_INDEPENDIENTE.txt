Aintegred - versión independiente

Esta versión conserva el HTML/CSS original del sitio para mantener su diseño.
El chat de texto usa /api/chat en este mismo servidor, en lugar de PluginsSystem.sendRequest('ai_text').

Para Render:
- Build: npm install
- Start: npm start
- OPENAI_API_KEY: tu clave de API (solo en Environment Variables)
- OPENAI_MODEL: gpt-5.6

No subas tu clave de API a GitHub.
