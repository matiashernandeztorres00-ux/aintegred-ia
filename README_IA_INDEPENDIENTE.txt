AINTEGRED — IA INDEPENDIENTE

Esta versión conserva el diseño original del sitio y cambia únicamente las solicitudes de texto de IA para usar /api/chat en tu propio servidor.

En Render:
- Build Command: npm install
- Start Command: npm start
- Environment variable: OPENAI_API_KEY = tu clave de API
- Environment variable: OPENAI_MODEL = gpt-5.6

No pongas tu API key en GitHub ni en archivos del navegador.

NOTA: Las funciones de login, archivos y generación de imagen/video siguen siendo las funciones originales del sitio. Esta modificación independiza específicamente el chat de texto de los créditos de IA de Site123.
